PERIOD
2026.10 — 2026.11

SUMMARY

세 브랜드를 담는
하나의 틀

세 개의 뷰티 브랜드를 가진 올에이지랩의 신규 홈페이지입니다. 마케팅팀의 초기 기획을 함께 다듬고, 디자인과 퍼블리싱은 혼자 맡았습니다.

정해진 타깃층이나 상세 정보가 없는 상태에서 마케팅팀이 원한 키워드에 맞춰 고급스럽고 깔끔한 인상을 기준으로 방향을 잡았습니다.

브랜드 페이지는 하나의 틀에 색과 이미지만 바꾸는 방식으로 설계해, 이후 제품 상세페이지에서 브랜드별 개성을 더할 수 있도록 했습니다.

KEY POINTS

디자인부터 배포까지

01

고급스럽고 깔끔하게

마케팅팀의 요청에 맞춰 장식적인 요소를 덜어내고, 여백과 정돈된 타이포로 화면을 구성했습니다.

02

브랜드 페이지 공통 틀

브랜드 페이지를 같은 레이아웃에 색과 이미지만 바꿔 일관되게 만들고, 브랜드별 개성은 제품 상세페이지에서 보여주도록 역할을 나눴습니다.

03

반응형 설계

데스크톱과 모바일을 설계하고, 태블릿 환경까지 직접 만들어 화면이 어떻게 바뀌는지 확인했습니다.

04

직접 구현과 배포

HTML을 PHP 파일로 구성하고 CSS · JS를 정리해 FileZilla로 서버에 올렸습니다. SEO 기본 세팅도 완료했습니다.

WORKFLOW

AI를 도구로 쓰는 작업 과정

AI가 만든 결과물은 의도를 먼저 파악하고, 제가 생각한 방향과 다르면 직접 수정하고 보완했습니다.

01

디자인 초안

기획안과 비슷한 뷰티 브랜드 레퍼런스를 바탕으로 초안 제작

02

섹션별 다듬기

섹션 구성, 폰트, 이미지를 하나씩 수정

03

피드백

마케팅팀 검토와 셀프 검토로 수정

04

AI 퍼블리싱

확정된 디자인을 AI를 활용해 코드로 구현

05

검수와 보완

오류와 의도와 다른 부분을 확인해 직접 수정

BRAND PAGES

하나의 틀, 세 개의 브랜드

클로베라와 닥터씨에이지는 같은 레이아웃에 브랜드별 색과 이미지만 바꿔 일관되게 만들었고, 출시 전인 뷰마셀은 Coming Soon 페이지로 따로 구성했습니다.

RESPONSIVE

데스크톱 · 태블릿 · 모바일

CHALLENGE

어려웠던 점

정확한 정보나 타깃층이 정해지지 않아 디자인 방향을 스스로 판단해야 했습니다. 비슷한 뷰티 브랜드 사이트를 폭넓게 참고하고, 회의 때 레퍼런스를 보여드리며 방향을 먼저 제안했습니다.

일정이 짧은 프로젝트라 디자인과 퍼블리싱을 먼저 진행한 뒤 수정하는 방식으로 속도를 냈습니다.

RESULT

결과

10월 초안 이후 11월 첫째 주에 1차 디자인을 확정하고 퍼블리싱까지 완료해 서버에 배포했습니다.

이후 콘텐츠 확정 전 단계까지 참여했습니다.
